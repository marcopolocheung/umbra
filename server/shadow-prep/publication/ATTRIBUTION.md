# Generation attribution template

Each local generation writes `ATTRIBUTION.json` from the admitted source manifest.
It must retain the DCP boundary notice, FABDEM CC BY-NC-SA 4.0 and modification
notice with terrain-family artifacts, Overture/OSM ODbL notices and any required
derivative-database access, CHMv2 CC BY 4.0 attribution (Meta, WRI and Vantor
imagery notice), and installed-grid notices. Building and canopy objects never
receive terrain-derived absolute values or FABDEM terms merely through composition.
